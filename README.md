# DENDROBOT

DENDROBOT is a Python desktop application developed to perform Hierarchical Agglomerative Clustering using Single Linkage, Average Linkage, and Complete Linkage methods. The application allows users to import Excel datasets, perform clustering analysis, and visualize results through dendrograms.

## Features

- Import dataset from Microsoft Excel
- Manual data input
- Hierarchical Agglomerative Clustering
- Single Linkage
- Average Linkage
- Complete Linkage
- Dendrogram visualization
- User-friendly GUI

## Technologies

- Python
- Tkinter
- Pandas
- NumPy
- SciPy
- Matplotlib
